# tasks

Tracks context and work items added to the `local-model` project to keep
working efficient. Add one note per context item or task so the project
stays easy to pick up again later.

## Naming

- `task-<number>.md` (e.g. `task-001.md`, `task-002.md`)

## Purpose

Record what context was added, why, and any decisions made — so future
sessions can resume without re-discovering the same information.
